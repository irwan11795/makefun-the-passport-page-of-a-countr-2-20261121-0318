# The Passport Page of a Country That Isn't There

An invented passport spread for the fictional Republic of Valdoria: an open passport showing a bilingual data page (portrait + machine-readable strip) and a visa/stamp page with a coherent June–July 2024 travel history through the neighbouring Dravnia and Kessar, plus a mountain-permit visa condition.

## Entry

`main.py` (Python 3.13, stdlib only) writes the pre-generated image to the output directory as `entry.png`.

## Status

Entry ready: `entry.png` (1024x683, flat-vector cartoon illustration of the fictional Republic of Valdoria passport spread) + `main.py` (stdlib-only copy).
